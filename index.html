ÄNDERUNGEN

One More Day v0.8.1

  • Snikkers Run im Handy-Querformat auf eine echte bildschirmfüllende Spielansicht optimiert.
  • Touch-Steuerung reagiert jetzt direkt auf pointerdown; Tap-Highlight, Textauswahl und Touch-Verzögerung auf dem Spielfeld wurden entfernt.
  • Musik und Spiel pausieren zuverlässig, sobald die PWA in den Hintergrund wechselt; die Musik setzt erst nach aktiver Rückkehr ins Spiel fort.
  • Optionaler Vollbild-Button ergänzt, sofern das Gerät die Fullscreen API unterstützt.
  • Hindernisse deutlich detailreicher gezeichnet und um Baumstumpf sowie Ast erweitert.
  • Snikkers Run als eigenes Minispiel in die gemeinsame PWA integriert.
  • Start über eine eigene Kachel; das Spiel öffnet innerhalb der bestehenden Dialog-/View-Struktur ohne Seitenreload.
  • Mobile-first: Tippen als Hauptsteuerung, Leertaste zusätzlich auf PC und Surface.
  • Vier Lauf-, zwei Sprung-, eine Lande- und eine Game-Over-Pose mit transparenten Snikkers-Sprites.
  • Persönlicher Bestscore wird ausschließlich lokal unter omd_snikkers_run_best_v1 gespeichert.
  • Das Minispiel ist vollständig vom Arbeitsguthaben, Geo-Check-in, Tagesstatus und Bonus-System getrennt.
  • Theme-Pfad vorbereitet: assets/audio/puppy_adventure_theme.mp3.
  • Beim Schließen wird der Runner vollständig zerstört; Animation, Audio und Event-Listener werden sauber beendet.
  • Bestehende Funktionen und Cloudflare-/D1-Logik aus v0.7.4 bleiben unverändert.
