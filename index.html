One More Day v0.9.9

  • v0.9.9: Alle drei Minigames zeigen Steuerungshinweise jetzt auch im Querformat und Vollbild vollständig an; Spielflächen werden ohne Abschneiden eingepasst.
  • v0.9.9: Snikkers Catch: Schokolade ersetzt den fälschlich geführten Schuh als −20-Hindernis; Legende korrigiert und Touch-Nachführung leicht beschleunigt.
  • v0.9.8: Snikkers Chase als drittes Minigame mit eigenem Cover, Standalone-Spiel und Vollbild-Unterstützung integriert.
  • v0.9.7: Bezeichnung und technische Struktur des ersten Minigames wurden vollständig auf Snikkers Run vereinheitlicht.
  • v0.9.7: Snikkers Catch wird im Handy-Hochformat kompakt statt über die gesamte Bildschirmhöhe gestreckt dargestellt.
  • v0.9.7: Snikkers Catch nutzt im Querformat/Vollbild die gesamte verfügbare Breite ohne seitliche helle Ränder.
  • v0.9.6: Snikkers Run besitzt jetzt zusätzlich eine direkt startbare Standalone-index.html.
  • v0.9.7: Feste Spiele-Struktur: jedes Minigame erhält künftig eine eigene direkt spielbare index.html.
  • v0.9.3: Admin kann ARBEIT/ZUHAUSE buchen oder widerrufen.
  • v0.9.3: FREI/KRANK kann als Von-Bis-Zeitraum beantragt bzw. administrativ gesetzt werden.
  • v0.9.3: Admin-Push bei echter User-Buchung und Cloud-Start-Sync korrigiert.
  • Web-Push-Grundfunktion für User-Handy und Admin-Handy ergänzt.
  • User-Handy kann Erinnerungs-Pushs aktivieren; Admin-Geräte sehen diese User-Aktivierung nicht.
  • Admin-Bereich enthält eine separate Registrierung ausschließlich für das Admin-Handy sowie einen Test-Push.
  • Service Worker verarbeitet Push-Nachrichten auch bei geschlossener PWA und öffnet One More Day beim Antippen.
  • Erfolgreiche ARBEIT-/ZUHAUSE-Buchungen vom User-Handy werden mit Geräte- und Buchungskennung an den Server gemeldet, damit später der Admin-Push eindeutig ausgelöst werden kann.
  • Minigames bleiben weiterhin Admin-only im Testmodus.
  • Guthaben, Check-in-Regeln, Abwesenheiten und bestehende Cloud-Daten bleiben unverändert.
